# 示例 · Route A 广度检索完整走查

展示宽泛开放主题的"两段式 swarm"：先轻量景观定框，再**多路广探**（Phase 1W，每面向一个调查单元并行/分轮）铺开广度，综合后再分维度深挖。这是本 skill 应对"帮我研究整个 XX 领域"类请求的差异化架构。

---

## 用户输入

> "帮我研究一下低空经济现在的整体情况。"

## Phase 0 · 路由判定

- 无文件；主题宽泛、开放、景观级、无明确切入角 → **Route A（广度检索）**。

> 输出一句话：「选 Route A：主题宽泛多面、无指定角度；先广探建立地貌，再分维度深挖。」

## Phase 1 · 轻量景观（3–5 搜，仅定框）

- 低空经济大致分：整机制造（无人机 / 电动垂直起降飞行器 eVTOL）、应用运营、基础设施（空域 / 起降 / 通导）三层 [^land1]。
- 关键张力：政策热度高 vs 商业闭环未跑通；载人出行前景 vs 适航与安全瓶颈。

## Phase 1W · 多路广探（识别 6 个面向，分轮派发）

> 并发上限约 4，故分两轮：第一轮 4 个面向，完成后第二轮 2 个。基线模式下主智能体串行完成，结果等价。

| 面向 | 输出文件 | 广探要点（≥10 搜/面向） |
|---|---|---|
| F1 技术版图（整机/零部件） | `research/lowalt_wide01.md` | 无人机与 eVTOL 构型路线、核心零部件国产化 |
| F2 商业/资本版图 | `research/lowalt_wide02.md` | 融资热度、代表企业、订单与估值信号 |
| F3 应用落地场景 | `research/lowalt_wide03.md` | 物流配送、载人出行、应急/农业巡检成熟度 |
| F4 基础设施（空域/通导/起降） | `research/lowalt_wide04.md` | 低空空域管理、通信导航、起降设施建设 |
| F5 风险与争议 | `research/lowalt_wide05.md` | 安全监管、盈利模式质疑、"概念泡沫"论 |
| F6 政策与标准 | `research/lowalt_wide06.md` | 适航认证、地方政策、空域改革进程 |

各面向刻意保留 ≥20% 重叠（如 F4 与 F6 都触及空域），为后续交叉验证埋点。

**单元输出格式**（`lowalt_wide05.md` 节选）：
```
## 面向：风险与争议
### 争议与冲突主张
- 乐观方：低空经济将成万亿级新增长极 [^opt1]
- 谨慎方：多数场景尚无稳定盈利模式，存在"政策热、商业冷" [^skeptic1]
### 建议深挖区域
- 各细分场景的真实单位经济性（客单价 / 成本 / 补贴依赖）
```

## 主智能体综合

读取全部 6 份 `wide{NN}.md`，合并为统一景观图，识别最有前景（F3 物流配送场景落地最实）与最具争议（F5 盈利模式之争）的区域，喂给 Phase 2。

## Phase 2 · 维度分解（≥10，节选。首次使用本 skill 可参考 `references/perspective-templates.md` 五视角起手式）

1. 技术：eVTOL 主流构型路线之争
2. 技术：核心零部件（电池/电机/飞控）国产化现状
3. 商业：代表企业与融资格局
4. 场景：物流配送落地成熟度
5. 场景：城市载人出行可行性
6. 基础设施：低空空域管理改革
7. 标准：适航认证与安全法规进度
8. 争议：市场规模预测与盈利模式
9. 地域：主要城市试点政策对比
10. 时间：未来 12 个月落地信号
    …

## Phase 3–5 · 深挖 + 交叉验证（节选）

每维度一个调查单元（≥20 搜），分轮派发。交叉验证时把不同来源对"市场规模"的预测比对，同时提取共识区与盲区：

```
## 共识区（Consensus Zone）★ 最高可信
- 物流配送是当前低空经济中落地最实的场景 —— F3、Dim04、Dim05 全部确认 [^f3][^dim04a][^dim05]
- 核心零部件（电池/电机/飞控）国产替代在加速 —— F1、Dim02 一致 [^f1a][^dim02]

## 冲突区
### 冲突 1：2030 年市场规模预测（类型：数值/口径）
- 立场A：约 2 万亿元 [^size1]（口径=含带动的关联产业）
- 立场B：约 5000 亿元 [^size2]（口径=低空飞行核心产业）
- 分析：口径不同（大口径含带动 vs 核心产业本体），并非真实矛盾。
  应并列标注两种口径，避免被单一数字误导。

## 盲区（Blind Spot）★ 研究缺口
- 低空噪声与社区接受度 —— 全部面向和维度均未涉及
- 低空飞行保险与责任体系 —— 仅 F6 浅提，未深挖
```
→ 触发 Phase 5 补搜，确认两数字分属"大口径/核心口径"，冲突降级为口径差异。

### Phase 4.5 · 认知自检

```
最不可靠主张：某城市"2026 年开通载人航线"的时间表仅来自地方规划文件 [^city3]
视角偏斜：偏重产业乐观叙事（全 6 面向均倾向"加速/机遇"），质疑声音集中于 F5 一隅，
  权重不够均衡
遗漏视角：航空公司/通航运营商的视角——eVTOL 替代传统短途航班的实际经济效益分析缺失
综合等级：B+（广探覆盖好、证据较充分；但乐观叙事偏重，建议在报告中主动提示读者注意
  这一倾斜）
```

## Phase 6 · 洞察（节选）

```
Insight: "低空经济万亿市场"之争的实质是统计口径差异，而非景气度分歧
Derived From: Wide-F5, Dim08
Rationale: 乐观数字多含带动的关联产业，谨慎数字仅计核心飞行产业；桥接后指向
  同一判断——核心产业规模尚小，增长依赖场景与盈利模式跑通
Implications: 短期确定性机会在"已跑通单位经济性"的物流/巡检场景，而非载人出行
Confidence: high

Action Insight: 作为产业投资者，不应追逐"万亿赛道"的宏大叙事，而应聚焦已经
实现正单位经济性的细分场景（物流配送/农业巡检）——它们不需要依赖"空域全面开放"
这一前置条件就能跑通商业闭环
Derived From: Dim04, Dim05, Dim08
Confidence: medium
```

## Phase 7 · 交付

- 按 `assets/report_template.md` 组装行研体报告：共识区→可信→冲突→盲区→洞察（含行动洞察）→认知自检。
- 跨面向洞察（桥接 F5 与 Dim08）是 Route A 的价值亮点，重点呈现。
- `scripts/dedup_citations.py research/` 合并全部广探+深挖引用。
- 认知自检中发现的"乐观叙事偏重"在报告中主动提请注意。
