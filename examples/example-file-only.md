# 示例 · Route C 纯文件研究完整走查

展示"用户上传多份文件 + 明确只基于文件"时的执行：文件深读 → 从主题分维度 → **仅文件**深挖（不联网）→ 跨文件矛盾消解 → 洞察 → 交付。引用指向**文件名+章节**而非 URL。这是本 skill "跨文档矛盾消解"能力最纯粹的体现。

## 用户输入

> （上传 3 份文件：`A_券商研报.pdf`、`B_行业协会白皮书.pdf`、`C_公司年报.pdf`）
> "**只根据我传的这三份材料**，帮我分析下这家公司 2025 年的经营状况和风险，不要上网搜。"

## Phase 0 · 路由判定

- 有文件 + 明确"只根据材料/不要上网" → **Route C（纯文件研究）**。
- 记录硬约束：**全程 0 次联网**，忠于用户意图。

> 输出一句话：「选 Route C：用户明确限定仅用上传文件；全程不联网，引用指向文件章节。」

## Phase F · 文件深读（`research/公司经营_file_analysis.md` 节选）

**文件清单**

| 文件 | 类型 | 一行摘要 |
|---|---|---|
| A_券商研报 | 卖方研报 | 看多，给"买入"评级，预测营收+25% |
| B_行业协会白皮书 | 行业报告 | 行业整体增速放缓至 8% |
| C_公司年报 | 一手披露 | 实际营收+12%，毛利率下滑 3pct |

**跨文件映射**
- 重叠主题：营收增速、行业景气、盈利能力。
- **矛盾**：A 研报预测营收 +25%，C 年报实际 +12% → 数值冲突（预测 vs 实际）。
- **互补**：B 提供行业基准（+8%），可用于判断 A/C 谁更合理。
- **缺口**：三份材料都未披露现金流细节（Route C 下仅记录，不联网填补）。

## Phase 2 · 维度分解（从文件主题派生，节选。即使是纯文件研究，也可参考 `references/perspective-templates.md` 的五视角框架辅助组织分析角度）

1. 营收增长：预测与实际的差异
2. 盈利能力：毛利率变动
3. 行业景气对标
4. 风险因素（各文件自陈）
5. 管理层口径 vs 第三方口径
   …（每维度映射到具体文件章节）

## Phase 4 · 交叉验证（`research/公司经营_cross_verification.md` 节选）

```
## 共识区（Consensus Zone）★ 三份文件全部一致
- 行业增速在放缓 —— A研报、B白皮书、C年报均以不同方式确认了这一趋势
  [^A-3.2][^B-3.1][^C-战略]

## 高可信
- 2025实际营收增长约12% —— C年报一手披露，且高于行业8%基准(B)，可信
  [^C-利润表][^B-3.1]

## 中可信
- 行业整体增速放缓至 8% —— B行业协会白皮书，行业半官方来源 [^B-3.1]

## 低可信
- 券商预测2025营收增长25% —— A研报，卖方前瞻、与一手年报冲突 [^A-3.2]

## 冲突区
### 冲突 1：营收增速 25% vs 12%（类型：数值/来源，预测 vs 实际）
- 立场A：+25% [^A-3.2]（券商预测，发布于年报前，口径=预期）
- 立场C：+12% [^C-利润表]（公司审计披露，口径=实际）
- 分析：非对等冲突——A为前瞻预测、C为已实现结果。以一手审计数据(C)为准，
  A的乐观预测未兑现。这本身是一条风险信号。

## 盲区（Blind Spot）★ 三份文件均未触及
- 现金流状况 —— 无任何文件提供现金流表数据，无法判断增长质量与偿债能力
- 客户集中度 / 应收账款质量 —— 未涉及
```

### Phase 4.5 · 认知自检（Route C 仅文件，无外部校验，自检更关键）

```
最不可靠主张：券商研报的 +25% 增长预测 [^A-3.2]（已被年报证伪，且卖方存在评级激励）
视角偏斜：三份文件全部来自"看好/中立"型信源（券商研报 + 行业协会 + 公司自述），
  无任何独立第三方或质疑方视角，属于严重的来源结构偏斜——报告中必须向读者示警这一点
遗漏视角：公司竞争对手的对比数据、下游客户端的真实反馈——均不在给定材料中，但会显著
  影响公司判断
综合等级：C+（文件间交叉验证基本完成，但来源结构严重偏斜于乐观/中立方；在无独立质
  疑方文件的情况下，仅凭这三份材料无法做出均衡判断。报告中需将这一局限性放在开篇显眼
  位置声明）
```

> Route C 特则：**跳过 Phase 5**（不许联网）。冲突与局限按原样记录，认知自检偏差警示带入报告。

## Phase 6 · 洞察提炼（`research/公司经营_insight.md` 节选）

```
Insight: 卖方预期与公司实际业绩存在系统性高估，叠加毛利率下滑，构成"预期差"风险
Derived From: Dim01, Dim02
Rationale: A预测+25%但实际仅+12%(C)，同时毛利率降3pct(C)，说明增长质量弱于叙事
Implications: 若市场定价仍锚定卖方乐观预期，存在估值回调风险
Confidence: high

Action Insight: 作为投资决策者，仅凭这三份文件无法安全判断公司真实健康状况——
关键缺口（现金流、客户质量、竞对表现）需要至少补充一份独立审计报告和一份行业第三方
评测才能覆盖。在补全之前，建议将结论定位为"公司自述+行业基准交叉比对"，而非完整尽调
Derived From: Dim01, Dim04, 认知自检-综合等级
Confidence: high
```

## Phase 7 · 交付

- 报告首部**明确声明**："本报告仅基于所提供的 3 份文件，未进行任何外部检索。"
- 认知自检的 C+ 等级和来源偏斜警示放在开篇显眼位置，让读者第一时间知道本报告的置信边界。
- 按模板组织：共识区→可信→冲突→盲区（现金流缺口等）→洞察（含行动洞察）→认知自检。
- 引用全部指向**文件名+章节**（非 URL）。
- 运行 `scripts/tally_confidence.py research/` 得可信度画像（本例 Low 占比偏高且来源结构偏斜，已在认知自检和报告开篇如实说明）。
