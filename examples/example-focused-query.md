# 示例 · Route B 聚焦检索完整走查

本示例展示一次典型执行的**输入 → 路由 → 维度 → 取证 → 交叉验证 → 洞察 → 交付**全链路，供理解 skill 的实际运行方式。为可读性做了压缩（真实执行维度更多、检索更密）。

---

## 用户输入

> "帮我分析一下 2025 年国内固态电池的产业化进展，哪些企业量产了，有哪些技术路线之争？要带出处。"

## Phase 0 · 路由判定

- 无上传文件 → 排除 C/D。
- 主题具体有界（固态电池产业化，含明确子问题：量产企业、技术路线之争）→ **Route B（聚焦检索）**。
- 含时间约束"2025 年" → Epistemic Reset 记为硬约束。

> 输出一句话：「选 Route B：主题具体、维度可识别；时间窗锁定 2025 年，检索用中文。」

## Phase 1 · 景观扫描（粗到细，5 搜）

- L1 宏观：固态电池分半固态/全固态；2025 年处于半固态量产、全固态中试阶段 [^cnki1]。
- L2 结构：主要玩家——整车厂、电池厂、材料厂三类；技术路线分硫化物/氧化物/聚合物/卤化物。
- L3 张力：出现"全固态量产时点"分歧——有说 2027，有说 2030 后 [^news1][^report1]。

## Phase 2 · 维度分解（示例取 10 个，此处列 6。首次使用本 skill 可参考 `references/perspective-templates.md` 的五视角起手式起步）

1. 技术路线：硫化物路线现状与代表企业
2. 技术路线：氧化物/聚合物路线现状
3. 量产进度：半固态电池装车企业盘点
4. 量产进度：全固态中试/送样时间线
5. 资本与政策：国家/地方支持与投融资
6. 争议：全固态量产时点之争（乐观 vs 保守）
   …（7–10：供应链材料、成本、海外对比、专利格局）

## Phase 3 · 并行深挖（每维度一个调查单元，节选 Dim06 证据）

`research/固态电池_dim06.md` 片段：

```
Source: 学术访谈B

Excerpt: "从材料与工艺成熟度看，大规模量产窗口更可能在2030年后"
Confidence: medium
```

## Phase 4 · 交叉验证（`research/固态电池_cross_verification.md` 节选）

```
## 共识区（Consensus Zone）★ 最高可信
- 半固态电池路线是量产主流，2025年已装车 —— Dim03、Dim04、Dim07、Dim09 全部确认
  [^cnki1][^news1][^dim09]

## 高可信
- 2025年半固态电池已实现装车量产 —— Dim03、Dim07 独立确认 [^cnki1][^news1]

## 中可信
- 硫化物被多数企业视为全固态终极路线 —— Dim01 单一权威来源 [^dim01a]

## 冲突区
### 冲突 1：全固态大规模量产时点（类型：时间/解读）
- 立场A：2027年小批量 [^news-a]（企业规划，口径=小批量装车）
- 立场B：2030年后大规模 [^interview-b]（专家判断，口径=大规模量产）
- 分析：口径不同（小批量 vs 大规模）+ 立场差异（企业规划 vs 独立专家）。
  非纯数值矛盾，二者可部分调和：小批量2027、规模化2030后。列为可调和冲突。

## 盲区（Blind Spot）★ 研究缺口
- 固态电池退役回收与循环利用 —— 全部 10 个维度均未触及
- 固态产线对现有锂电设备的重用/改造程度 —— 未覆盖
```

### Phase 4.5 · 认知自检

```
最不可靠主张：全固态 2027 量产的说法仅来自企业规划，无独立验证 [^news-a]
视角偏斜：偏重产业端（电池厂/车企/券商），终端用户与环保视角缺失
遗漏视角：固态电池的矿产资源端（锆、镧等关键原料）未纳入维度设计
综合等级：B（证据较充分、覆盖广度良好，但非产业视角有欠缺，建议补研矿产与退役端）
```

## Phase 5 · 定向复核

对"量产时点"冲突补 3 搜，确认业界普遍区分"小批量装车（2027 前后）"与"规模化降本（2030 后）"两个里程碑，冲突**降级为口径差异**，在报告中并列呈现。

## Phase 6 · 洞察提炼（`research/固态电池_insight.md` 节选）

```
Insight: "全固态量产时点之争"本质是里程碑口径之争，而非技术判断分歧
Derived From: Dim04, Dim06
Rationale: 乐观方指"小批量装车"，保守方指"规模化降本"，二者时间线并不真正冲突
Implications: 投资者应区分"装车验证"与"成本拐点"两个节点，避免被单一时点叙事误导
Confidence: high

Action Insight: 作为投资者，不应被"2027 全固态来了"的叙事驱动仓促布局，而应紧盯
半固态装车渗透率与材料成本下降曲线的真实交叉点——那是真正的拐点信号
Derived From: Dim04, Dim05, Dim06
Rationale: 小批量装车并不解决成本竞争力问题；规模化降本取决于材料突破，时间线更靠后
Confidence: medium
```

## Phase 7 · 交付

- 运行 `scripts/tally_confidence.py research/` 得可信度画像（含共识区、冲突清单）；`scripts/dedup_citations.py research/` 合并引用。
- 按 `assets/report_template.md` 组装报告：共识区→可信→冲突→盲区→洞察（含行动洞察）→认知自检，全文 `[^id]` 溯源。
- 用户未指定格式 → 默认交付 Word（若平台支持转换）。
